# Match Replays
An updated version of Curtis' Match Replays mod.


### Most notable changes
- Flexible factions now taken into account
- Replays continuing when leaving fixed
- Unique behavior for Vampire promotions; they show the player's original role instead of "Vampire"



Some contributions were done by @AlchlcDvl via "Match Replays Plus".
This is more or less that.

### Warning
Match Replays made before this update will not show at all.
